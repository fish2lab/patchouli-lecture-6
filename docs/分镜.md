# 分镜 · 第 6 集「心中有谱」

全片一块黑板。帕秋莉站左（讲课），红美铃站右（厨师），琪露诺只在说话时从右下角冒头。每段末板擦擦净。
颜色：切 = 粉、水和锅温 = 蓝、先后 = 绿、当句结论 = 黄。

## 0 开场（约 32 秒）· 菜谱卡
1. 琪露诺问 → 左上写出一张「菜谱」卡：翻炒三分钟 / 盐 少许 / 油 适量 / 火候 看着办。
2. 「抽盲盒」→ 卡旁画一个打问号的纸箱「盲盒」；卡上「少许」「适量」「看着办」被粉圈圈住。
3. 美铃「不看谱」→ 起手式；菜谱卡被一道粉线划掉。
4. 「谱在她心里」→ 右上一颗粉心，里面写「心中有谱」（黄）。
5. 「当工程来拆，只有三件事」→ 卡底拉出箭头到「三件事」。
6. 「怎么切 / 水和锅温 / 谁先下锅」→ 三栏大字：切（粉）· 水（蓝）· 先后（绿），下面小字：纤维多长 / 锅温 / 时间表。

## 1 切（约 40 秒）· 肉块里的橡皮筋
肉块里画波浪纤维 = 橡皮筋 → 受热绷直 → 顺着切出长条（塞牙）→ 横着切成短段（一咬就开）→ 「横切牛羊顺切猪」→ 牛羊粗纤维横切 / 猪细纤维顺切 → 结论「纤维有多长」。

## 2 水和锅温（约 46 秒）· 锅剖面 + 温度表盘
锅 + 灶火 + 表盘（指针高）→ 湿菜下锅指针掉，变「水煮」→ 沥干 / 吸干 → 空锅冒烟指针升 → 放大：肉片下的「蒸汽垫」→ 琪露诺靠近，指针往蓝里掉（冰花）→ 恢复 → 盐把水从叶子里拉出来 → 青菜晚放盐、肉早腌。

## 3 先后（约 40 秒）· 下锅时间表
厚薄两块的受热剖面「越厚越慢」→ 时间轴 → 白杆 1 分钟 / 绿叶 30 秒（同一终点）→ 杆先下、叶后下 → 肉片变白先盛出 → 配菜、肉回锅合炒 → 锅温曲线最高点淋料酒 → 「关火」线之后放鸡精蚝油 → 整条轴框成「时间表」。

## 4 辣椒炒肉（约 50 秒）· 步骤条 + 三色徽章
标题「辣椒炒肉」+ 切 / 水 / 序三枚徽章 → ① 备肉（顺纹切、吸干、盐→水→粉→油）→ ② 干煸辣椒（虎皮）→ ③ 煸油滑肉 → ④ 合炒、料酒 → 生抽 : 蚝油 : 老抽 = 2 : 1 : 0.5 → ⑤ 出锅（红油、没有水汤）→ 琪露诺「没看表」→ 三个生熟信号：肉由红变白、青菜塌下变深绿、筷子扎透。

## 5 结尾（约 36 秒）· 心中有谱
「玄学手感」被划掉 → 大心形「心中有谱」→ 心里写进 纤维 · 水 · 先后，旁边小卡「菜谱 · 参考」→ 美铃：只改一处（两片叶子，早盐那片出水）→ 板擦擦掉对照，琪露诺的「冷水下锅」锅被冻成冰块 → 帕秋莉合上书；底部出处。
