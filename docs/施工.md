## 接口（黑板风，照第 5 集）

- 画法全在 `src/lec/chalk.js`（`ck*`）：`ckRoom` → `ckCam` → `ckLayer(c, cam, lc => {...})`，所有粉笔内容画在 `lc` 上；`ckWrite` + `ckText` 写字（字号 ≥ 30）；`ckLine` / `ckShape` / `ckArrow` / `ckBadge` / `ckBorder` / `ckUnderline` / `ckRing`。
- 写字时画粉笔头：`ckWrite` 返回 `{ head, writing }`，`ckStick(c, ckToScreen(cam, ...head), tau)` + `ckDust`。
- 站位和共用小图标在 `src/props.js`：`ogPch` / `ogMei` / `ogCirno`、`ogOutro` + `ogEraser`（段末擦黑板）、`ogWok`（锅剖面）、`ogFlame`（灶火）、`ogMeat`（带纤维的肉块）、`ogGauge`（温度表盘）。
- 音效：`scene({...})` 之后 `sfx(key, [[t, 'chalk'|'line'|'felt'|'tap'|'whoosh', dur], ...])`；不写就按台词自动配。
- **台词不改**：`seq` 里的文字、`who`、顺序和 `docs/方案.md` 逐字一致（语音已生成，改字就没声音）。可以改 `mood`、`pause`、`hold`，以及最后的段长。

## 版面规则

- 内容区：x 500–1400，y 70–860（帕秋莉占 x 170–430，美铃占 x 1530–1790）。
- 琪露诺说话时，x > 1220 且 y > 540 的地方不放东西。
- 段首 0.6 秒黑板是空的；段末用 `ogOutro` 擦干净，最后 0.25 秒是空黑板。
- 颜色：切 = pink，水和锅温 = blue，先后 = green，当句关键结论 = yellow，其余 ink / muted。
- 每句只加一个新画面元素；关键句后画面停约 1.2 秒（用 `hold`）。屏幕上只写正在念的关键词。
- 一段一个主物件，撑到底、逐句变形。
