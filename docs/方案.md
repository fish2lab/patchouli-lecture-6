# 方案 · 第 6 集「心中有谱」

## 一句话

让**照菜谱做饭总像抽盲盒的人**，在**约 5 分钟**内记住：菜谱背后只有三件事：**纤维多长、水和锅温、谁先下锅**。记住这三件，就能脱谱。

## 受众和时长

- 受众：会开火、但离了菜谱就慌的人。
- 时长：约 5 分钟，6 段，台词 45 条以内。

## 主线（3 个新概念）

1. **纤维是橡皮筋**：刀决定纤维有多长。横切牛羊顺切猪。
2. **水是锅温的敌人**：沥干、烧透锅（蒸汽垫不粘锅）、青菜出锅前放盐。
3. **先后是时间表**：越厚越慢。杆先叶后，肉滑熟先盛出，料酒趁锅最热，鸡精关火后。

第四段把三件事放进一道「辣椒炒肉」里对照，再讲「看食材信号，不看秒表」。

- 帕秋莉：讲课。一辈子照书办事的图书馆魔法使，偏偏照谱做饭像抽盲盒。这是本集的反差，结尾她合上书。

## 台词（各段文件里的 seq 必须和这里逐字一致）

### 0 开场 `opening`
1. 【琪露诺】帕秋莉！美铃炒的菜，为什么比你照书做的好吃？
2. 我照着菜谱做，每次都像抽盲盒。
3. 【美铃】我做菜从来不看谱。
4. 不看谱，是因为谱已经在她心里了。
5. 今天把做菜当工程来拆。菜谱背后，其实只有三件事。
6. 怎么切，怎么管住水和锅温，谁先下锅。

### 1 切 `cut`
1. 先说切。生肉的纹理，其实是一捆捆细橡皮筋。
2. 一受热，这些皮筋就猛地缩紧、绷直。
3. 【琪露诺】那顺着切呀！长长的，多整齐！
4. 整齐，但长皮筋熟了以后，牙齿咬不断，就塞牙。
5. 迎着纹理横着切，皮筋全变成小短段，一咬就开。
6. 【美铃】所以厨房里说：横切牛羊顺切猪。
7. 牛羊纤维粗硬，必须切断；猪肉细嫩，顺着切，下锅不容易碎。
8. 刀不是在切肉，是在决定纤维有多长。

### 2 水和锅温 `heat`
1. 第二件事：水，是锅温的敌人。
2. 湿菜倒进热油锅，锅温一下掉下去，爆炒就变成了水煮。
3. 【美铃】所以青菜要沥干，肉片要用厨房纸吸干。
4. 锅也一样。空锅先烧到微微冒烟，再倒凉油下肉。
5. 肉片表面那点水瞬间变成蒸汽，垫在下面，肉就不粘锅。
6. 【琪露诺】那我站在锅边，锅是不是就凉了？
7. 所以今天你离灶台远一点。
8. 盐也会把水拉出来。青菜早放盐，就会出汤变软。
9. 青菜出锅前再放盐；肉反过来，要提前用盐腌。

### 3 先后 `order`
1. 第三件事：先后。热从表面走到中心要时间，越厚越慢。
2. 蒜苗的白杆要炒一分钟，绿叶三十秒就熟。
3. 【美铃】所以杆和叶分两堆，杆先下，叶后下。
4. 肉片也一样。滑到表面变白，先盛出来。
5. 底油炒熟配菜，再把肉倒回去合炒。
6. 料酒要等锅最热的时候，沿锅边淋，酒气一蒸，腥味就走了。
7. 鸡精和蚝油怕高温，关火以后再放。
8. 【琪露诺】原来做菜就是排时间表！

### 4 辣椒炒肉 `dish`
1. 把三件事放进一道辣椒炒肉里试试。
2. 【美铃】瘦肉顺纹切片，吸干水，抓盐，抓水，裹粉，封油。
3. 【美铃】辣椒不放油，先干煸，逼出水汽，煸到起虎皮。
4. 【美铃】空锅烧透，肥肉煸出猪油，下蒜，再大火滑肉。
5. 肉一变白，辣椒回锅，锅边淋料酒。
6. 生抽、蚝油、老抽，大约二比一比半。
7. 【美铃】关火撒鸡精，出锅。盘底一层红油，没有水汤。
8. 【琪露诺】可是美铃一次都没看表啊？
9. 不看表，看食材。肉由红变白，青菜塌下变深绿，筷子扎得透，就熟了。

### 5 结尾 `ending`
1. 所以大厨不看谱，不是靠玄学手感，而是心中有谱。
2. 纤维，水，先后。想清楚这三件，菜谱就只是参考。
3. 【美铃】下回试试只改一处，比如青菜出锅前放盐，看它出不出水。
4. 【琪露诺】那我来试冷水下锅！咦，锅呢？我把锅冻住了。
5. 今天这本书，我就不翻了。去厨房吧。

## 视觉隐喻

全片一块黑板（照第 5 集的黑板风）。每段末尾板擦擦干净，下一段从干净黑板开始。

| 段 | 主物件 | 怎么接下一段 |
|---|---|---|
| 0 开场 | 一张菜谱卡（「翻炒三分钟」「盐少许」），后来变成「盲盒」问号，再被擦掉，留下三个板书标题：切 / 水 / 先后 | 「切」字下面画出一块肉 |
| 1 切 | 一块肉（粉框）里的纤维 = 波浪橡皮筋，受热绷直；顺切是长条，横切是短段 | 短段肉片落进锅 |
| 2 水和锅温 | 炒锅剖面 + 温度表盘指针，水滴让指针掉，烧透让指针升；蒸汽垫；盐把水拉出叶子 | 表盘指针 → 时间轴 |
| 3 先后 | 一条横的时间轴（下锅时间表），食材标签按时间落到轴上 | 时间轴留着当骨架 |
| 4 辣椒炒肉 | 同一条时间轴变成辣椒炒肉的步骤条，每一步标上「切/水/序」三色徽章；最后三个生熟信号 | 三色徽章收成三个字 |
| 5 结尾 | 三个字（纤维 / 水 / 先后）合成一张「心中有谱」卡，和开场菜谱卡对照 | 片尾 |

三件事的颜色全片固定：**切 = 粉（pink）**、**水和锅温 = 蓝（blue）**、**先后 = 绿（green）**；黄（yellow）只给当句的关键结论。

## 被否掉的方案

- 22 条全讲：每条 10 秒，什么也记不住。只挑能归到三件事里的。
- 讲淀粉、猕猴桃嫩肉、清汤浓汤乳化：好听，但是第四、五个概念，砍掉。
- 用真菜照片或 AI 图：违反本系列规则，全部粉笔画。
